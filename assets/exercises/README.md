# Встроенный справочник

`catalog.json` содержит 127 упражнений с названиями на английском, русском и казахском. JSON включён в Flutter assets: для загрузки не нужны сеть, Firebase или вход в аккаунт.

## Источник

- [yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db).
- Версия: `f00c92c7dcf1216a928a52c3706c7ce8e2f71ed5`, файл `dist/exercises.json`.
- Лицензия: Unlicense; исходный текст сохранён в `LICENSE.txt` и включён в assets.
- SHA-256 исходного JSON записан в `source.sha256` внутри справочника.

Отбор редакционный: распространённые упражнения для силовой тренировки со штангой, гантелями, гирей, блоками, тренажёрами и собственным весом. Это не рейтинг популярности по статистике. Варианты, отличающиеся оборудованием или движением, сохранены отдельно; отдельные дубли «с дополнительным весом» не нужны — дополнительный вес вводится в подходе. Кардио, растяжка, техника и изображения в эту поставку не входят.

## Поля и изменения

- `id` = `free-exercise-db/` + исходный ID. Он не зависит от перевода; не менять его при переименовании, поскольку программы и история ссылаются на ID.
- `names.en` — исходное название; `ru` и `kk` — переводы. Казахский перевод требует вычитки носителем перед выпуском.
- `muscleGroup` — первая основная группа мышц из источника. `equipment` — значение из источника; `null` означает, что источник не указал оборудование. Это технические ключи, не локализованные подписи интерфейса.
- `measure` — `reps` для динамических движений, `time` для обычной и боковой планки.
- `usesBodyWeight` явно задаёт применение правила продукта «вес тела + дополнительный вес». Отмечены упражнения без внешнего отягощения, а также брусья, горизонтальные подтягивания, гиперэкстензия, подъём коленей на брусьях и ролик для пресса. Наличие опоры или снаряда само по себе не делает упражнение упражнением с внешним весом. Для движений со штангой, гантелями и грузовым стеком флаг выключен.
- У встроенных упражнений нет владельца. Личные упражнения и правки пользователя будут храниться отдельно при реализации хранения; общий JSON ими не перезаписывается.

JSON — редактируемый источник данных приложения. Добавляя упражнение, сверить исходную запись, сохранить стабильный ID, заполнить все три перевода и явно проверить способ измерения и флаг веса тела. Не заменять справочник автоматической загрузкой всей внешней базы: в источнике нет наших переводов и правил измерения.

Загрузка: `AssetExerciseCatalogRepository` → `exerciseCatalogProvider`. Провайдер готов для будущих экранов выбора упражнения, но сами экраны пока не подключены.

Проверки: `rtk proxy flutter test test/domain/exercise_catalog_test.dart test/data/exercise_catalog_repository_test.dart`. Они загружают настоящий Flutter asset, проверяют ошибки формата, переводы, идентификаторы и использование записей в логике тренировок.
