Нижняя стеклянная панель с пятью разделами: Главная, История, Прогресс, Люди, Профиль.

Передай: активный раздел.

- Материал — `glass-strong` с размытием `glass-blur`, скругление `radius-xl`, тень `shadow-float`. Панель парит над контентом с полем `space-2` от краёв.
- Активная вкладка — цвет `accent-text` на подложке `sunken`. Остальные — `ink-muted`.
- У каждой вкладки иконка и подпись; подпись не скрывай. Самые длинные подписи — казахские, проверяй ширину на них.
- Высота области касания не меньше `touch-min`.
- На экранах, открытых поверх вкладок (конструктор, тренировка, подопечный), панель не показывается.
- На Android допустимо заменить стекло на непрозрачную `surface`, если размытие тормозит.
