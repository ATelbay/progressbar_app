Плавающая стеклянная панель, в которой человек записывает результат упражнения. Главное место приложения.

Передай: название упражнения, план, значения прошлой тренировки, чем измеряется упражнение (повторения или время), с собственным ли оно весом.

- Панель прижата к низу экрана поверх списка упражнений. Материал — `glass-strong` с размытием `glass-blur`, скругление `radius-xl`, тень `shadow-float`.
- Три строки: подходы, повторения, вес. Вес — `num-hero`, остальное — `num-lg`. Число стоит слева под своей подписью, оба степпера — справа, под большим пальцем.
- Поля заранее заполнены результатом прошлой тренировки по этому упражнению. Если его нет — планом.
- Количество подходов запоминается и подставляется в следующий раз.
- Степперы размером `action-height`: вес меняется на 2,5 кг, повторения и подходы — на 1. Касание по числу открывает клавиатуру.
- План показан над полями тихо: `num-sm`, `ink-muted`.
- Одна залитая кнопка — «Записать». Под ней текстовая «Добавить каждый подход»: она открывает полный режим, выбор запоминается в настройках.
- Упражнение на время: строка «Повторения» заменяется на «Время» с единицей «с».
- Упражнение с собственным весом: строка «Вес» называется «Доп. вес», ноль допустим.

Не размещай в панели ничего, кроме ввода текущего упражнения: комментарии, завершение и отмена тренировки находятся на экране.
