Строка одного подхода: план слева, факт справа, отклонение в конце.

Передай: плановые вес и повторения, фактические вес и повторения (их может не быть), единицу измерения («кг» или «с»).

- План — `num-sm`, `ink-muted`. Факт — `num-md`, `ink`. Не меняй их местами и не выравнивай по размеру.
- Отклонение считай сам и показывай плашкой со знаком и словом: «по плану», «−5 кг, −2», «+2,5 кг». Цвет — `success` или `warning`, но смысл несёт текст.
- Нет факта — тире цветом `ink-muted`, без плашки.
- Подход сверх плана: в колонке плана тире, плашка «сверх плана».
- Для упражнения на время вместо «× 8» показывай секунды: «60 с».

Не используй строку для сводки по упражнению в упрощённом режиме — там одна строка «3 × 8 × 60 кг».
