Прогресс тренировки в виде грифа: один блин — одно упражнение дня.

Передай: сколько упражнений в тренировке, сколько выполнено и какое идёт сейчас.

- Выполненный блин залит `accent`. Текущий — прозрачный с контуром `accent-text`. Остальные — `sunken` с контуром `line-strong`.
- Гриф — `line-strong`, замок в конце — `ink`.
- Рядом всегда счётчик «3 из 5» цифрами `num-md`: блины не заменяют число.
- Блины одинаковой ширины с зазором `space-2`. Если упражнений больше восьми, уменьшай ширину блина, но не убирай зазор.
- Для чтения с экрана задавай подпись «Выполнено 3 из 5 упражнений».

Используй на карточке активной тренировки на «Главной» и в шапке экрана тренировки. Для других процессов (загрузка, отправка данных) не используй.
