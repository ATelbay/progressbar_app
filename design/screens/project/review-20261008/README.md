## Тренировка — исправлено по уточнению владельца

Вместо сравнения А/Б страница показывает простой ввод существующей кастомной клавиатурой. Клавиатура открыта сразу, активное число подчёркнуто: подходы → повторения → вес. Одна нижняя кнопка «Продолжить» переводит к следующему полю и ничего не записывает. На весе она называется «Записать итог» и записывает все значения разом. Можно коснуться любого поля для исправления. Первое нажатие цифры заменяет подставленное число; последующие дописывают. Запятая доступна только для веса. Системная клавиатура чисел не открывается, кнопки «−/+» при вводе не показываются.

- После последнего шага карточка отмечается «Завершено», панель переходит к следующему незаписанному упражнению. Порядок элементов не меняется.
- По умолчанию показан режим **«Итогом»**, которым пользовался владелец. В «По подходам» ввод начинается с повторений; для упражнения без плана после первого подхода предлагается явное «Закончить упражнение». Это предложение поведения, не принятое решение.
- **«Вне плана»** показывается до и после записи. Результат и завершение обозначены отдельно от сравнения с планом.
- У завершённого упражнения вне плана в своей программе доступно **«Добавить в план»**: подтверждение с выбором дня и редактированием подставленного результата. Оно меняет только будущий план; снапшот текущей тренировки и пометка «Вне плана» сохраняются. В варианте программы тренера действия нет. Поведение ещё нужно согласовать.
- «Добавить упражнение» добавляет один фиксированный пример («Разгибание рук на блоке»). Сам поиск в этом этапе не макетируется.

## Планирование

Один общий вариант последовательного ввода: все значения видны, активное поле выделено, цифровая панель вводит подходы → повторения → вес. «Продолжить» переходит к следующему полю, «Готово» сохраняет всё и закрывает лист. Можно касаться любого поля для исправления.

Примеры: неизвестный вес, прошлый результат, сохранённый план, упражнение на время и собственный вес. Шесть кнопок ±0,5 / ±1 / ±5 кг доступны только при известном исходном весе и заменяются клавиатурой по касанию числа. Для упражнения на время ввод заканчивается секундами; для собственного веса указывается дополнительный вес, включая 0. Необязательная заметка раскрывается отдельно.

Цифровая панель — предложение развития уже существующей панели веса. Макет не воспроизводит нативную клавиатуру iOS/Android. Нужны отдельные проверки Flutter после реализации. Начальные 3 подхода и 10 повторений соответствуют текущему коду, но остаются в «К обсуждению».

## Границы

Это макет, а не изменение поведения Flutter. Владельцем подтверждены пометка «Вне плана», кастомная клавиатура с последовательным переходом между полями нижней кнопкой, «Продолжить» → «Готово» в планировании, шаги только для известного веса. Явное завершение в режиме по подходам и порядок добавления в будущий план пока обсуждаются. Выбор новой компоновки А/Б не требуется.

Владелец уточнил, что проблема с незавершённой карточкой возникла **в режиме «Итогом»**. Ранее найденное удержание панели при добавлении подходов не объясняет этот случай. Реальная причина остаётся открытой; правильное поведение в HTML-макете не доказывает исправление Flutter-приложения.
