Тренировка и планирование

Progress Bar · варианты для обсуждения. Все изменения остаются внутри макета.

Кастомная клавиатура открыта сразу. Введите подходы, нажмите нижнюю кнопку, затем повторения и вес. До последнего нажатия результат не записывается.

Подходы → повторения → вес

Активное число подчёркнуто. Одна нижняя кнопка: «Продолжить», на весе — «Записать итог».

Ввод: клавиатура одна, меняется только активное поле. Можно сразу нажать на нужное число. «Продолжить» не сохраняет промежуточные результаты.

«Добавить в план»: берёт записанный итог как начальные значения и просит подтверждение. Меняется только будущий план своей программы. У текущей тренировки остаётся исходная копия плана и пометка «Вне плана».

Чужая программа: переключатель сверху позволяет посмотреть вариант для программы тренера. Действия изменения плана там нет. Поведение ещё обсуждается.

Ввод по очереди

Все значения видны сразу. «Продолжить» переводит к следующему; «Готово» сохраняет весь лист.

Что проверить

  1. Введите подходы, нажмите «Продолжить», затем повторения и вес.
  2. Нажмите любое поле, чтобы исправить число. На весе одно «Готово» закрывает весь лист.
  3. Выберите «Есть прошлый результат»: на весе доступны шаги ±0,5 / ±1 / ±5 кг. Касание числа открывает клавиатуру.
  4. В примере «Новый вес» кнопок шага нет. Упражнение на время заканчивается вводом секунд.

В макете предложена одна общая цифровая панель для всех чисел — развитие уже используемой панели веса. Заметка остаётся необязательной.

Начальные 3 подхода и 10 повторений взяты из текущей реализации. Эти значения по умолчанию ещё находятся в «К обсуждению».
